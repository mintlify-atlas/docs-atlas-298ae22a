Alto connects to all your cloud storage services from a single native desktop application. Whether you use a major hosted service or run your own self-hosted server, Alto gives you a unified interface to manage and sync your files. Each provider you add becomes a **remote** — a named connection that you can pair with one or more local directories for syncing.

## Supported Providers

Alto supports seven cloud storage providers across two authentication models: **OAuth** (where Alto handles the login flow and no credentials are stored locally) and **credentials-based** (where you supply a server URL, username, and password directly).

| Provider | Auth Type | Notes |
|---|---|---|
| Google Drive | OAuth | Name only required |
| Dropbox | OAuth | Name only required |
| Nextcloud | Credentials | Server URL + username + password |
| OwnCloud | Credentials | Server URL + username + password |
| pCloud | OAuth | Name only required |
| Proton Drive | Credentials | Username + password + optional TOTP |
| WebDAV | Credentials | Server URL + username + password |

<Note>
  Alto's OAuth browser flow is planned for the full backend release. In the current version, OAuth-based remotes (Google Drive, Dropbox, pCloud) are created immediately using only a display name — no browser authentication takes place yet. Additional providers will be added in future releases.
</Note>

### Additional Providers

The following providers are part of Alto's data model. pCloud and Proton Drive do not yet have dedicated documentation pages — their login dialog support is planned for a future release.

- **pCloud** — OAuth-based, name only required
- **Proton Drive** — Credentials-based with optional TOTP two-factor authentication
