Google Drive is one of the most widely used cloud storage services, and Alto makes it straightforward to connect. Because Google Drive uses OAuth for authentication, Alto does not ask you for a password — the only thing you need to provide is a **display name** that identifies this remote within Alto.

## Prerequisites

You need an active Google account with Google Drive storage. No additional configuration is required on the Google side — all authentication is handled through the OAuth flow initiated by Alto.

## Adding a Google Drive Remote

<Steps>
  <Step title="Open the login dialog">
    Click the **+** button in the Alto sidebar to open the **Log In** dialog.
  </Step>
  <Step title="Select Google Drive as the server type">
    In the **Server Type** dropdown (labelled "Server Type"), select **Google Drive** from the list of available providers.
  </Step>
  <Step title="Enter a display name">
    Type a display name for this remote in the **Name** field. This name appears in the Alto sidebar and is used to identify the remote throughout the app.

    The name must pass the following validation rules:

    - It cannot be empty.
    - It cannot duplicate the name of an existing remote.
    - It must match the allowed character pattern:

    ```text
    ^[0-9a-zA-Z_.][0-9a-zA-Z_. -]*[0-9a-zA-Z_.-]$
    ```

    In plain terms, names must:
    - Only contain numbers, letters, `_`, `-`, `.`, and spaces
    - Not start with `-` or a space
    - Not end with a space

    If the name fails validation, the field will be highlighted and a tooltip will display one of the following messages:

    | Situation | Error message |
    |---|---|
    | Field is empty | `Name cannot be empty` |
    | Name already in use | `Name already exists.` |
    | Invalid characters or format | `Invalid name. Names must:\n- Only contain numbers, letters, '_', '-', '.', and spaces\n- Not start with '-' or a space\n- Not end with a space` |
  </Step>
  <Step title="Click Log In">
    Once the name is valid, the **Log In** button becomes active. Click it to add the remote. The new Google Drive remote will appear in the Alto sidebar immediately.
  </Step>
</Steps>

## Name Validation Pattern

The full regular expression applied to remote names is:

```text
^[0-9a-zA-Z_.][0-9a-zA-Z_. -]*[0-9a-zA-Z_.-]$
```

Some valid examples:

```text
My Google Drive
work.drive
personal_backup-2024
```

Some invalid examples:

```text
-backup          (starts with a hyphen)
My Drive         (ends with a space — trailing space not visible)
```

<Note>
  Alto's OAuth browser authentication flow is planned for the full backend release. In the current version, clicking **Log In** creates the remote immediately without opening a browser window or exchanging tokens with Google. Once the real backend is integrated, the OAuth flow will launch automatically after you click Log In.
</Note>
