Alto brings all of your cloud storage into a single, cohesive desktop experience. Built on Electron with a fully native GTK4/Adwaita UI — rendered through the gtk-js component library — Alto looks and feels right at home on modern Linux desktops while remaining cross-platform at its core. Whether you manage a personal Google Drive, a team Nextcloud server, or a mix of half a dozen providers, Alto gives you one consistent place to configure remotes, define sync directories, and track the status of every file in flight.

## What is Alto?

Alto is a port of [Celeste](https://github.com/hwittenborn/celeste), the original Rust/GTK4/Libadwaita file sync client, rebuilt for Electron and React. The port targets a full 1-to-1 functional mock of Celeste's UI, driven by the gtk-js React component library that exposes native GTK4 and Adwaita widgets. This combination gives Alto the visual fidelity of a native Linux application while opening the door to macOS and Windows users.

At its heart, Alto is a **multi-remote sync manager**. You register one or more cloud remotes in the sidebar, assign local directories to each remote, and Alto keeps them in sync. Each sync directory has a live status indicator so you can see at a glance whether a directory is fully synced, currently syncing, checking for changes, in an error state, or disconnected.

## Supported Providers

Alto supports a broad range of cloud storage providers out of the box. The login dialog lets you pick your provider, enter the required credentials, and have a new remote ready in seconds.

| Provider | Auth Method | Notes |
|---|---|---|
| Google Drive | OAuth | Name-only setup; auth handled via OAuth flow |
| Dropbox | OAuth | Name-only setup; auth handled via OAuth flow |
| Nextcloud | Username & Password | Requires server URL |
| OwnCloud | Username & Password | Requires server URL |
| pCloud | OAuth | Name-only setup; auth handled via OAuth flow |
| Proton Drive | Username & Password | Supports optional TOTP |
| WebDAV | Username & Password | Requires server URL |

## Architecture

Alto's renderer process is a React application that communicates with the Electron main process over typed IPC channels (modeled after GitHub Desktop's channel pattern). Window management operations — close, minimize, toggle maximized, set decoration insets — are all handled through these typed channels, keeping the GTK4 UI layer cleanly decoupled from Electron's native APIs.

The build pipeline uses Electron Forge with a Vite plugin, packaging the app as an ASAR archive with hardened Electron Fuses enabled at package time (cookie encryption on, Node.js CLI inspect disabled, ASAR integrity validation on).
