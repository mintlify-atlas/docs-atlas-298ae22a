## What Alto Does

Alto lets you connect to multiple cloud storage providers and keep local directories in sync with remote paths. You can monitor sync status in real time, resolve file conflicts, and control exactly which files get synced with glob-based exclusion patterns.

## Get Started in Three Steps

<Steps>
  <Step title="Install Alto">
    Download the latest release for your platform from the [installation page](/installation).
  </Step>
  <Step title="Add a Cloud Remote">
    Open Alto and click the **+** button in the sidebar to connect your first cloud storage account. See [Adding a Remote](/guides/adding-a-remote) for a walkthrough.
  </Step>
  <Step title="Configure Sync Directories">
    Pick a local folder and a remote path to sync. Alto will keep them in sync and alert you to any errors. See [Sync Directories](/guides/sync-directories) for details.
  </Step>
</Steps>

## Supported Cloud Providers

Alto supports a range of cloud storage services out of the box:

| Provider | Type |
|---|---|
| Google Drive | OAuth |
| Dropbox | OAuth |
| Nextcloud | Username + Password |
| OwnCloud | Username + Password |
| pCloud | OAuth |
| Proton Drive | Username + Password |
| WebDAV | Username + Password |

<Tip>
  More providers will be added over time. See the [Cloud Providers](/providers/overview) section for setup details for each one.
</Tip>
